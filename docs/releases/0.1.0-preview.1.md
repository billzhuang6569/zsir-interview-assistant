# 庄Sir采访录制助手 v0.1.0-preview.1

完全本地的采访录制工具。此次是开发预览版，不是已通过长时间采访验收的正式稳定版。

## 下载与使用

- **macOS Apple Silicon 或 Intel / macOS 14+**：按芯片选择 macOS arm64 或 x86_64 包并解压，打开“庄Sir采访录制助手.app”。使用临时本机签名，未经过 Developer ID 签名和 Apple 公证；系统可能阻止首次打开。请按 macOS 的应用安全提示检查来源，不要关闭系统安全功能。允许摄像头、话筒和屏幕录制权限；更新开发版后可能需要重新授权。
- **Windows x64 / Windows 10 2004+；Windows ARM64 / Windows 11**：解压对应架构的 Windows 包（自带 .NET 8 运行环境），先双击 `Install-RecordingTools.cmd`。脚本从 gyan.dev 下载 FFmpeg 9.0.2，并核对固定 SHA-256；不改系统执行策略，不安装驱动。若已下载下方固定版本的官方压缩包，可改名 `ffmpeg.zip` 放在程序旁，再运行安装脚本，同样校验哈希。然后双击 `ZSirCapture.Windows.exe`。仅首次安装编码工具需要网络，录制完全离线。Windows 可执行文件尚未签名，可能出现 SmartScreen 提示。
- 默认保存到用户“影片/视频”目录下 `ZSir Recordings`。素材保存在本机，不上传。

## 本次功能

- REC / Zsir 图标、暗色紧凑小窗及可折叠实时预览。
- macOS：摄像头+话筒、桌面+系统声音，可选单路或双路；支持异常素材恢复副本。
- Windows：显示器和系统播放设备选择，桌面+系统声音录制；摄像头尚未实现。
- 两端均有时:分:秒计时、15 秒无操作收起至屏幕边缘的小红圈、点击展开。停止或异常时恢复主窗口。
- Windows 保存 H.264/AAC `desktop.mp4`，同时保留分离视频与原始声音，便于异常检查；这些中间文件会增加磁盘占用。

## 已验证与限制

macOS 原生 UI、采集合成检查及边缘提示自检；Windows 11 实机桌面/系统音频短录、静音时间线、音画同步、重复开始/停止、编码器中断及边缘提示。详细结果见仓库 docs/testing。

尚未验收：1 小时以上真实采访、会议共存、所有多屏/DPI 环境、断电与磁盘故障、Final Cut Pro 导入。Windows 自动恢复界面和摄像头录制未实现。Windows 使用软件编码以兼容已测显卡驱动，长录制性能仍待验证。

## 新增架构包

补充 macOS Intel（x86_64）与 Windows ARM64 包，应用功能沿用本预览版。Windows ARM64 的应用和 .NET 运行时为 ARM64；当前安装脚本提供的 FFmpeg/ffprobe 为 x64，通过 Windows 11 仿真运行，因此并非全链路原生 ARM 编码。性能与设备支持仍需实机验证。Mac Intel 交叉编译并通过 Apple Silicon 上的 Rosetta 自检，不代表已通过 Intel 物理机器采集验收。

Windows ARM64 包已在 Windows x64 上使用 .NET SDK 8.0.426 交叉构建，PE 架构及许可检查通过。曾连通 ARM 虚拟机，但后续 Tailscale SSH 连接超时，未完成 ARM 虚拟机启动和录制验收。详见 `docs/testing/windows-arm64-2026-10-21.json`。原有 macOS ARM64、Windows x64 包保持不变；新增包沿用同版应用源码，仓库新增架构打包参数与验证记录，原版本标签不移动。
