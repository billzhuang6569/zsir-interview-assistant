# 庄Sir采访录制助手 v0.2.0 · 四平台

本次同版本提供 macOS ARM64、macOS Intel、Windows x64、Windows ARM64 四个压缩包及 SHA256SUMS.txt。

## 更新

- macOS 录制设置按摄像头/麦克风和桌面分组，新增实时预览、电平、多屏缩略图选择与高级设置。
- 统一省空间、标准、高画质三档；桌面按目标屏幕实际像素调整码率，默认标准保持旧版参数。
- 桌面声音默认开启，可关闭并生成无音轨视频；设备和质量选择持久化，目标失联时阻止开始而非换屏。
- macOS 录屏权限浮窗显示真实 App Icon，可拖出应用文件；跟随系统设置窗口，只放外侧，两边放不下时隐藏，不遮挡设置。
- macOS 自动恢复为可选项，默认关闭，只生成恢复副本、不自动续录。
- Windows 同步桌面质量、多屏缩略图、系统声音开关和播放设备选择。

## 安装

先停止并保存录制、退出旧版，再替换应用文件。升级不删除素材。

Mac 需 macOS 14+，Apple Silicon 使用 arm64，Intel 使用 x86_64。解压打开应用，按需授予摄像头、麦克风和录屏权限。签名变化可能要求重新授权。

Windows x64 需 Windows 10 2004+，ARM64 需 Windows 11 ARM。解压后运行 Install-RecordingTools.cmd，再打开 ZSirCapture.Windows.exe；包内自带 .NET。FFmpeg 9.0.2 由安装脚本从 gyan.dev 下载并校验，未包含在发布包中。离线可将 https://www.gyan.dev/ffmpeg/builds/packages/ffmpeg-9.0.2-essentials_build.zip 下载为程序旁的 ffmpeg.zip；SHA-256 为 60F467265B1E312373DBCD92200C2618A74850F98D3D078E94296BB3FA2047BA。ARM64 的 FFmpeg 使用 x64 仿真。

## 验证与限制

Mac 构建、录制核心/权限/UI 自检及不遮挡位置检查通过；Windows 构建及档位参数检查通过。用户已确认本机设置体验。真机录制与多屏热插拔、长录性能、Windows 完整媒体回归、Intel Mac 与 Windows ARM 原生采集仍未全部验收。详见 docs/testing/recording-settings-2026-10-22.md。

Mac 为 ad-hoc 签名，未 Developer ID 签名或公证；Windows 无发行签名。系统可能提示安全限制，请核对来源并遵循系统提示，不关闭安全保护。正式发布渠道不等于长采访可靠性已验收。

默认素材目录为用户影片/视频中的 ZSir Recordings。请先短试录，检查声音与画面。Windows 仅桌面录制，保留中间素材，磁盘占用高于成品估算。
