# 庄Sir采访录制助手 0.5.1

## Windows 界面重做

- Windows 界面层从 WinForms 改为 WPF，按 Mac 版的结构和[视觉稿](../design/windows-0.5.1-wpf-mock.html)重新绘制：
  - 深色窗口，Windows 11 上使用系统圆角和 Mica 背景
  - 图标统一为 Segoe Fluent Icons
  - 状态、计时、机位、预览、开始按钮按统一的间距和圆角排列
- 文字和图标按系统缩放清晰渲染；窗口在不同缩放比例的显示器之间拖动时会重新排版。
- 预览卡片在没有画面时显示占位提示。没有摄像头时显示「未检测到摄像头 · 重新检测」，可以直接重试。
- 设置窗重新排版：
  - 显示器卡片两列等宽
  - 摄像头和话筒合为一组
  - 「在录屏里隐身」和保存位置移到「高级设置」
- 录制中的状态色与 Mac 一致：桌面机位不再显示摄像头状态点；「远程可见」标签会提示当前未隐身。

## 验证与范围

- 在 Windows 11 中文实机（100% 缩放，未接摄像头）上：
  - 构建 0 警告 0 错误。
  - 主窗口、设置窗、高级设置、边缘收起在模拟的 1.0 / 1.25 / 1.5 / 2.0 倍缩放下全部通过布局检查：没有控件被裁切，也没有控件互相重叠。
  - 用合成摄像头源测试了「只录摄像头」和「摄像头+桌面」，都通过；没有摄像头时会正确拒绝录制。
- 该测试机的默认播放设备录不到系统声音，所以桌面段的声音和画面同步检查没有完成（与 0.5.0 相同，属于环境问题）。
- 录制、隐身和摄像头逻辑与 0.5.0 相同，Mac 版没有功能变化，只是版本号一起升到 0.5.1。
- **尚未验收**：真实的 125%–200% 系统缩放，以及 0.5.0 中列出的其他项目，详见 [0.5.0 验证与范围](0.5.0.md)。
