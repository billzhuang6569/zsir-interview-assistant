# 庄Sir采访录制助手 0.4.1

## 本次修复

- Mac：所选显示器失联或预览启动失败后，稳定显示错误，不再因清理状态或窗口激活无限重试、闪烁。重新选择设备或手动收起再展开可重试；不会自动改录其他屏幕。
- Mac：预览清理与录制状态分离，过期预览回调不会覆盖新录制状态；清理期间禁止启动新采集和设置。
- Mac：持续隐藏左上角系统关闭、最小化与缩放按钮，窗口布局、激活及关闭设置弹窗后也不会重新显示。保留右上角退出按钮及原生焦点、弹窗行为。
- Windows 功能未改动，仅统一构建版本为 0.4.1。

## 验证与下载范围

本机 Mac 已验证失联屏幕错误稳定、重新选择 Studio Display 恢复实时预览、收起与展开预览，以及窗口系统按钮在启动、布局和关闭设置后保持隐藏。预览失败恢复回归与原有生命周期检查通过。

提供 macOS 13+ ARM64 / Intel、macOS 12.3+ ARM64 / Intel 兼容版、Windows x64 / ARM64 六包。兼容版不录系统声音；Windows ARM64 录制工具仍通过 x64 仿真运行。本轮不新增 Windows 实机或旧版 macOS 采集验收。

Mac 仍使用临时签名（ad hoc），未完成 Developer ID 签名及 Apple 公证。替换应用后可能需要在应用授权引导中重新确认权限，或在系统设置刷新授权并重新打开。

## 延续的已知限制

0.4.0 的未通过项仍保留：Mac 摄像头源开头可能约 0.1 秒黑画面；Windows x64 短录同步检查曾出现约 447 ms 偏差，来源尚未完全区分；ARM64 连续启停第 3 次触发提交内存预算保护，未通过 20 次循环。云端 Mac 硬件编码检查曾失败；两小时长录、全部硬件/旧系统及完整剪辑软件导入尚未完成验收。

详见 [0.4.0 验证与限制](https://github.com/billzhuang6569/zsir-interview-assistant/blob/main/docs/releases/0.4.0.md)。本补丁不将这些未完成项标记为通过。
