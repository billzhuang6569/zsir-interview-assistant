# 庄Sir采访录制助手 0.5.2

这是 Windows 版的紧急修复，建议使用 0.5.1 的 Windows 用户升级。Mac 版没有功能变化，只是版本号一起升到 0.5.2。

## 修复

- **高缩放屏幕上看不到小窗**：0.5.1 在系统缩放不是 100% 时把小窗放到了屏幕外面。程序其实在运行，托盘也有图标，再次打开只会提示「已经运行」。现在小窗会正确出现在屏幕右上角。
- **Windows 10 上默认无法开始录制**：隐身默认开启时，录制边缘红点隐藏失败，程序因此取消录制。现在红点改为不透明窗口，隐身可以正常生效。
- **小窗找不回来**：托盘「显示小窗」，以及切换显示器或改变缩放时，都会把小窗拉回屏幕内。
- **错误提示**：隐身失败时不再提示升级 Windows，改为说明小窗未能隐藏以及如何处理。
- **崩溃日志**：意外错误会弹出提示，并写入 `%LOCALAPPDATA%\ZSirCapture\crash.log`。

## 验证与范围

- 在 Windows 10 21H2 中文实机（3840×2160，300% 缩放）上：
  - 用户肉眼确认小窗显示正常，窗口坐标在屏幕内。
  - 桌面录制通过：3 次声音和闪屏的时间差不超过 0.04 秒；边缘收起、展开、异常中断恢复都通过。这是该项检查首次在实机上完成。
  - 用合成摄像头源测试「只录摄像头」和「摄像头+桌面」，都通过。
- **已知问题**：同一台机器上，模拟 1.25 倍和 1.5 倍缩放的布局检查仍报告 1 个设备像素的超出（主窗口右上角标签、设置窗「高级设置」按钮）。目前未发现影响使用。
- **尚未验收**：真实的 125% 和 150% 系统缩放、多显示器和混合缩放、真实摄像头。其他项目见 [0.5.0 验证与范围](0.5.0.md)。
