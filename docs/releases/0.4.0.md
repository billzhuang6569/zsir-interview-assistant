# 庄Sir采访录制助手 0.4.0

## 本次更新

- 固定 30 fps 输出时间轴，统一录制起点与停止边界，修复停止时末帧被裁掉的问题。
- 桌面分辨率与画质独立设置：1080p、1440p、原始尺寸；已有原始尺寸配置继续保留。
- Mac 编码器初始化移至准备阶段，修复首次摄像头录制因初始化耗时触发调度失败的问题。每路使用独立有界写入队列，改善一路阻塞对其他路的影响。
- 录前预览、收起预览和边缘录制控制；设置按钮固定为齿轮。准备、录制、保存和设备清理时禁止打开设置，防止误触影响录制。
- Windows 对采集及编码能力做实际短片探测，记录回退原因；关闭预览时在缩放和 JPEG 编码前停止预览分支，主录制继续。
- 增强停止、设备清理与恢复副本的边界处理；恢复保留原素材，清理未结束时继续持有素材锁。Windows 大文件收尾预算按大小与时长计算。

## 下载与系统范围

提供六个客户端 ZIP：macOS 完整版 ARM64 / Intel、macOS 12 兼容版 ARM64 / Intel、Windows x64 / ARM64。

- macOS 完整版最低 13.0；macOS 12 兼容版最低 12.3，兼容版不录制系统声音。
- Windows x64：Windows 10 2004+ / Windows 11。Windows ARM64：Windows 11；客户端为 ARM64，录制工具仍通过 x64 仿真运行。Windows 当前仅支持桌面与系统声音。
- Mac 包使用临时签名（ad hoc），未完成 Developer ID 签名及 Apple 公证。
- 随附录制工具的对应源码、许可证、更新索引与 SHA-256 清单。更新索引保留旧版本兼容历史。

## 实测与已知限制

Mac 本机摄像头及双路短录的零起点、精确 1/30 秒时间戳、完整末帧和解码检查通过；录制中点击齿轮没有打开设置或打断录制。启动时相机源可能产生约 0.1 秒黑画面，当前保留真实源帧，不按像素亮度过滤暗场。

Windows ARM64 虚拟机已完成桌面短录、预览开关、音画偏移和 7 段素材逐帧 CFR 检查。连续启停在第 3 次触发 512 MiB 提交内存预算保护而停止，未通过 20 次循环验收；原因尚未完全定位，不能视为长期稳定性通过。原始素材保留。

两小时长录、会议/游戏并发性能、完整剪辑软件导入，以及所有旧系统/硬件组合尚未完成验证。单显示器以外的 Windows 映射保留 GDI 回退；HDR、混合 GPU、N 版等环境未全面验证。请在重要录制前用实际设备短录并检查画面与声音。

本次发布不表示整个 0.4.0 Milestone 的全部性能与稳定性验收已关闭。完整证据见仓库 `docs/testing/0.4.0-local-validation-2026-10-29.md` 与 `docs/testing/0.4.0-hosts-2026-10-29.md`。
