# 0.4.0 开发测试版（尚未发布）

本分支用于录制性能、恒定帧率与稳定性验证，尚不是通过完整验收的发行版本。不要替换唯一的正式录制环境；测试输出使用独立目录并保留原素材。

已实现待验：30 fps 输出时间轴、独立桌面尺寸设置（均衡/清晰/原生）、旧配置保留原生尺寸、录前预览及设备交接、预览限频、部分资源预算与故障监控、窗口和画质选项交互修正。

明确未完成：Windows 现代采集/硬件编码路径、录制中隐藏预览后的生产端零开销、完整恢复入口、macOS 阻塞媒体队列时有时限的停止、各平台原生设备/长录/性能与剪辑软件验收。因此不能宣称 milestone 已完成或资源下降目标已经达到。

## 系统范围

- macOS 12 以前从本版本起不维护，历史版本停留 0.3.0；此政策不代表历史包支持其原本未支持的系统。
- 当前代码最低为 macOS 12.3。12.3+ 兼容版保留桌面无系统声音的边界；macOS 13+ 完整版与 14+ API 路径分别验证。Intel 和 Apple Silicon 分别交付测试结果。
- Windows 10 2004+/11 x64；Windows 11 ARM64 当前录制组件仍为 x64 仿真，不宣称原生 ARM64 编码。Windows 仍只提供桌面与系统声音。

## 测试要求

先使用独立测试目录录制短片，验证画面、声音、时长、设备释放与重复启停。再运行仓库时间轴检查和原生验收，最后测试会议/游戏并发长录。文件显示 30 fps 不代表实际运动帧足够，必须检查重复帧和内容流畅度。

当前云端验证记录见 `docs/testing/0.4.0-cloud-validation-2026-10-29.md`。Linux 交叉编译与语法检查不替代本地 Mac、Windows x64 和 Windows ARM64 设备验收。测试包没有公证/正式签名发布承诺，也不会更新正式下载或自动更新渠道。
