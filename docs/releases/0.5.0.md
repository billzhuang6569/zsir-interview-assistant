# 庄Sir采访录制助手 0.5.0

## 新功能

- **全平台「在录屏里隐身」开关**（默认开启，与以前行为一致）
  - 开启：录制画面、远程协助和会议共享都看不到小窗。
  - 关闭：远程协助（ToDesk、向日葵等）可以看到并操作小窗。
    - Windows：小窗也会被录进桌面画面，每次开始录制前会提示确认。
    - Mac：本应用自己的录制仍然不会录到小窗。
  - 如果隐身时在远程端看不到小窗，可以这样切换：
    - Windows：用任务栏托盘图标的菜单切换，菜单里也能显示小窗、开始/停止录制、打开素材目录。
    - Mac：在菜单栏的应用菜单里切换。
  - 录制、保存、恢复期间不能切换。`report.json` 会记录本次是否隐身。
- **Windows 支持摄像头和话筒**：三种机位与 Mac 一致（摄像头 / 桌面 / 摄像头+桌面）。
  - 摄像头单独保存为 `camera.mp4`：H.264 8 Mbps，配话筒声音。
  - 自动优先选择 MJPEG 1080p30。
  - 没有摄像头、被 Windows 隐私设置禁止、被会议软件占用时，都有中文提示；不会自动换成别的设备。
  - 新增 `--device-check <目录>`，用于检查摄像头和话筒。
  - 升级后默认机位仍是「桌面」。

## Windows 界面修复

- 修复高缩放比例（125%–200%）屏幕上文字被裁切、按钮被挡住、标题错位的问题。界面改为按系统缩放自动排版，窗口拖到其他显示器上也会重新适配。
- 主窗口按 Mac 的结构重排：状态、计时、机位选择、预览，底部是开始按钮加文件夹和设置两个图标。
- 设置窗改为深色。屏幕选择卡片显示「显示器 1（主）· 分辨率」和显示器名称，不再出现 `\\.\DISPLAY1`，文字也不会再压在缩略图上。
- 修复多处可能出现的乱码：
  - 禁用按钮的浮雕灰字
  - FFmpeg 日志中的中文路径和设备名
  - 安装包说明改为带 BOM 的 `README.txt`
  - 报告中的中文改为直接写入，不再转义

## 验证与范围

- 提供 macOS 13+ ARM64 / Intel、macOS 12.3+ ARM64 / Intel 兼容版、Windows x64 / ARM64，共六个包。Windows ARM64 的录制工具仍是 x64 版本，靠系统仿真运行。
- 在 Windows 11 中文实机（100% 缩放，未接摄像头）上：
  - 构建 0 警告 0 错误。
  - 隐身开关、界面布局（模拟 1.0–2.0 倍缩放）、边缘收起都通过检查。
  - 用合成摄像头源测试了「只录摄像头」和「摄像头+桌面」：两路的成品时长相差 0.2 秒；每一路画面与自己声音的时长差不超过 0.3 秒。
  - 没有摄像头时会正确拒绝录制。
  - 设备检测正确列出了中文名的话筒，并成功录到了话筒声音。
- 该测试机的默认播放设备录不到系统声音，所以桌面段的声音和画面同步检查没有完成。0.4.1 在同一台机器上也一样失败，属于环境问题。
- **尚未验收**：
  - 真实摄像头的格式选择、被占用和拔线
  - 真实的 125%–200% 系统缩放
  - 远程协助软件下开启和关闭隐身时实际看到的效果
  - 长时间录制的同步
  - 摄像头轨的恢复副本（原始素材会保留，但暂不能自动恢复）

  遇到问题请附上 `--device-check` 生成的 devices.json 和对应素材的 report.json。
- Mac 仍使用临时签名（ad hoc），没有做 Developer ID 签名和 Apple 公证。
