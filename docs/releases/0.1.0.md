# 庄Sir采访录制助手 v0.1.0（macOS）

此次 GitHub 正式 Release 更新 macOS 客户端。Windows 未修改，请继续下载 [v0.1.0-preview.1](https://github.com/billzhuang6569/zsir-interview-assistant/releases/tag/v0.1.0-preview.1) 中对应架构的 Windows 包。

## 更新

- 第一次打开新增权限设置引导：选择录制方式 → 逐项授权 → 完成设置。
- 仅申请所选机位需要的摄像头、话筒或屏幕录制权限；提供系统设置入口、返回后重新检查及重新打开应用说明。
- 支持稍后设置、中断后继续、设置中重新进入；开始录制前检查当前权限，缺失时先补齐，不创建录制素材。
- 主界面「双路」改为「摄像头+桌面」；移除「素材仅保存在本机」及空白占位，保留录制与保存提示。

## 下载与使用

macOS 14+：Apple Silicon 下载 arm64 包，Intel 下载 x86_64 包，解压后打开「庄Sir采访录制助手.app」。先停止旧版本录制并等待保存、退出后再替换应用。首次启动按引导设置；引导完成不会自动开始录制。建议先短试录，检查保存的视频和声音。

默认素材在 `~/Movies/ZSir Recordings`，可在设置中更改。升级保留已有素材和配置；采用原 bundle identifier，签名变化仍可能导致系统要求重新授权。

## 验证与已知限制

权限状态与持久化自检使用模拟回调，不代表实际系统授权全部通过。具体构建、UI 与媒体自检结果见 [本次验收记录](https://github.com/billzhuang6569/zsir-interview-assistant/blob/v0.1.0/docs/testing/macos-onboarding-2026-10-21.md)。

- macOS 包采用临时 ad-hoc 签名，未经过 Developer ID 签名或 Apple 公证；可能被系统安全提示阻止，请核对来源并按系统提示操作，不要关闭安全保护。
- macOS 14、Intel 物理机器、新用户完整授权/拒绝/重启回路及 VoiceOver 人工验收尚未全部完成。交叉编译与 Rosetta 检查不能代替真实硬件验收。
- 1 小时以上采访、会议共存、断电/磁盘故障、Final Cut Pro 导入仍需验证。正式 Release 表示发布渠道，不等于以上可靠性验收已完成。
