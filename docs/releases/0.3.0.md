# 庄Sir采访录制助手 v0.3.0 · 六包发布

## 更新

- macOS 13+ 完整版新增自动版本检测：每日空闲时检查，高级设置可手动检查、关闭自动检查或选择自托管 HTTPS 更新清单。GitHub 为默认来源，提示后由用户下载，不自动安装；录制、保存和恢复期间不打扰。
- macOS 完整版最低系统降为13.0；另提供macOS12.3+独立兼容版（M芯片/Intel）。兼容版摄像头包含麦克风，桌面仅画面、无系统声音；本版不提供自动检测，可与完整版并存。
- Windows完整包内置编码工具及.NET，完整解压后直接打开，无需运行CMD、配置PATH或联网安装依赖。工具由固定FFmpeg/x264源码构建，发布对应完整源码和构建脚本。
- 六包版本与校验和统一生成，按系统、架构及产品版别分开下载，避免完整版误下载兼容版。

| 安装包 | 最低系统 |
| --- | --- |
| ZSirCapture-0.3.0-macos-arm64.zip | macOS13，M芯片 |
| ZSirCapture-0.3.0-macos-x86_64.zip | macOS13，Intel |
| ZSirCapture-0.3.0-macos12-arm64.zip | macOS12.3，M芯片；桌面无声音 |

停止并保存、退出旧版后再替换应用。Mac按需授予摄像头/麦克风/屏幕权限。macOS12到系统偏好设置→安全性与隐私→隐私，解锁后勾选，按系统提示退出再打开。macOS12.0–12.2不支持。Windows完整解压，保留tools和运行时文件，不要只复制EXE。

v0.2.0没有检测功能，需手动升级一次。v0.3.0完整版才可检测后续更新。更新检查不上传素材；关闭自动检查后只在点击检查时联网。仅镜像更新清单不等于镜像安装包。

## 验证边界

Mac两架构构建及兼容路径自检不等于macOS12/13真机验收，目前缺这些旧系统实机；Intel采用Rosetta检查。Windows x64在用户实机执行最终包短录制、音画同步、完整解码及异常保留检查；Windows ARM64未完成物理设备采集验收。Windows只录桌面与系统声音，尚无摄像头/麦克风录制和自动恢复界面。

macOS为ad-hoc签名、未公证，Windows无发行签名。短录和自动化检查不代表长采访可靠性；先试录确认画面、声音和磁盘空间。不同DPI/多屏/睡眠/拔设备/断电及1小时以上录制仍需专项验收。详细证据见docs/testing与本轮milestone文档。
