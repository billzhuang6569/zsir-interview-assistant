# 庄Sir采访录制助手 0.6.0

本次更新降低Mac待录预览占用，修复原生5K桌面录制的编码失败，并改进Windows摄像头共享采集及异常素材恢复。六个平台包同版本发布。

## Mac

- 待录预览缩小到长边最多640像素，目标10fps；预览启动状态仅在变化时通知界面，避免每帧刷新整个窗口。
- 本机debug构建、内置设备、双路待录预览的三个5秒窗口对比，单核CPU均值从24.75%降至10.45%，下降约58%。这是单机短测，不代表所有电脑或整机能耗；内存没有观察到降低。
- 正式录制沿用原有输出尺寸、画质和30fps配置。本机三次双路短录正常保存，六份成片完整解码与时间轴检查通过，摄像头1920×1080、桌面1920×1240、H.264/AAC及目标码率均保持一致。
- 原生尺寸任一边超过4096像素时改用硬件HEVC，保留原生像素，避免本机5120×2880首帧H.264写入的AVFoundation -11800 / 底层-12903错误。实际编码器和底层错误链写入诊断。

## Windows

- 摄像头改用系统MediaCapture SharedReadOnly / MediaFrameReader，覆盖录制、主界面预览、设置预览和设备诊断；不回退到独占DirectShow采集。
- 摄像头画面通过有界命名管道交给配套FFmpeg，麦克风继续使用共享WASAPI。请保留并使用本版完整tools目录，不要混用旧版工具。
- 补齐camera与双路异常恢复：camera配microphone.wav，desktop配system-audio.wav，各自使用对应起始时间；旧报告格式继续兼容。
- 元数据不足时保留原音频并明确生成待检查的视频副本，不猜测同步；原素材不覆盖，活动录制目录由排他锁保护。

## 素材声音

- desktop.mp4：系统播放声音。
- camera.mp4：所选话筒。扬声器外放可能被物理话筒再次拾入，建议采访时戴耳机。本次未添加回声消除或改变声音处理。

## 验证与已知限制

- Mac：预览状态/尺寸检查、完整录制核心合成检查、兼容构建，以及上述三次本机双路短录通过。成片仍有补帧计数，不能以固定30fps或零丢帧报告替代动态流畅度验收。
- Windows：x64/ARM64构建及离线管道、恢复音源隔离检查；本版配套工具在Windows打包时执行编码/解码检查。共享摄像头实际效果仍取决于设备、驱动和会议软件。
- **尚未完成**：Windows新共享后端与飞书的物理机并发、完整camera故障恢复实机检查、优化后Mac飞书专项、真实外接5K回归、2小时长录、20次启停和剪辑软件导入验收。0.4.0稳定性milestone继续开放，不宣称全部目标已经达成。
- Mac最低系统：完整版macOS13+；macOS12兼容版12.3+，桌面不含系统声音。Intel及旧系统本轮没有物理机验收。
- Windows最低系统保持Windows10 2004+（x64）/Windows11 ARM64；ARM64包的FFmpeg仍使用x64仿真。
- 本版仍未提供发行签名或macOS公证，沿用既有分发方式；遇到安全提示请核对来源并遵循系统提示。
