## 2026-10-21 本轮结果

- 构建通过；`CaptureChecks` 五组检查通过：目录/报告不覆盖、空采集拒绝成功、三种模式合成素材对应文件及双轨检查、4K 编码与全分辨率解码、8 Mbps 合成素材时间轴/封装与完整音视频解码。
- 本机原生 UI 检查通过：双路切换到摄像头和桌面、预览占位随选择变化、折叠时缩小窗口、展开恢复、恢复双路待录状态。
- 录制管线预览已实现，但本轮未开启真实摄像头/话筒/屏幕采集；L01–L07 的实际权限、真实缩略图刷新、录制中锁定与折叠行为仍待实机验收。自动检查不能代替这些项目。
- 未提交、未合并、未部署。旧网页原型及远程文档保留为历史资料。

## 连续视频预览修订（2026-10-21）

- 从每秒静帧改为 AVSampleBufferDisplayLayer 连续显示，复用成功写入的像素缓冲区；预览使用独立样本包装，DisplayImmediately 不污染录制样本。
- 移除 CoreImage 图片生成和一秒限频。每路最多一个待送 UI 的预览任务，渲染器繁忙时丢预览帧，折叠停止传递。录制画质参数未改。
- 构建及六组合成检查通过，新增 60 个连续预览样本共享像素、即时显示标记、原录制元数据保持不变、音频拒绝进入预览的检查。
- 真实视频播放的帧率、延迟、折叠恢复与长时间负载仍待实机验收；合成检查不代表真实实时播放已验收。

### Windows 桌面短录补测

已通过 Tailscale 在已登录的 Session 1 执行真实桌面短录，报告见 [windows-desktop-2026-10-21.json](testing/windows-desktop-2026-10-21.json)。诊断使用 FFmpeg 9.0.2（来源为 FFmpeg 官网列出的 gyan.dev Windows builds），下载包经 SHA256 校验后传输并再次校验。一次性测试任务结束后已移除；未更改系统执行策略或显卡驱动。

- GDI 桌面采集 + libx264 软件编码，2560×1440，10.000 秒，平均 29.9 fps，26,447,585 字节；完整解码通过。
- 硬件编码首次尝试失败：该 FFmpeg 构建要求 NVENC API 13.1，当前驱动只提供 13.0。后续 Windows 引擎需选择兼容现有驱动的编码实现；这不是显卡不支持录制的结论。
- 成功视频保留在 Windows 用户 Videos/ZSir Windows Checks/Take-4e060ad5-ae64-438e-845d-e76f9d668a24/desktop.mp4；原失败报告和日志也保留。
- 这是独立诊断工具，不是 Windows 产品客户端；未验证 WASAPI 系统声音、摄像头、WGC 采集、会议共存或长录制。
- 可在已登录桌面、符合本机脚本执行策略的 PowerShell 中运行 script/windows-desktop-check.ps1，传入 FFmpegDirectory（同时含 ffmpeg.exe 与 ffprobe.exe）。默认录制 10 秒、不录音、不覆盖旧文件；输出到独立测试目录。


## Windows 原生客户端实测（2026-10-21）

通过 Tailscale 在用户已登录的 Windows 桌面运行 `clients/windows` 原生客户端，与真实按钮共用开始/停止路径。最终 Release 构建 0 警告、0 错误；完整结果见 [客户端实测报告](testing/windows-client-2026-10-21.json)。

- 所选桌面原像素 2560×1440、目标 30 fps、H.264；系统默认 ROG DELTA II 播放设备经 WASAPI loopback 录音，输出 AAC 48 kHz 双声道。不打开摄像头或话筒。
- 三次测试音与闪光标记对齐检查、5 秒静音间隔、首条完整音视频解码通过；第二条连续录制保留全静音音轨。具体时长和同步差值见 JSON。
- 无效播放设备拒绝启动；RF64 补静音及重复时间戳重叠检查通过。右上角小窗已通过成片静帧检查排除。
- 强制终止本次测试编码器后，客户端停止并明确标记 needs_review，保留分离音视频，并合成约 2.03 秒已落盘片段。初次发现短录 MP4 头仍在缓冲中，增加 flush_packets 后重新实测通过。此项不代表断电或整个应用强杀恢复验收。
- 测试画面曾被其他应用遮挡，造成闪光识别失败；仅将测试场景置顶后重跑通过，未关闭其他应用。
- Windows 桌面放置“庄Sir采访助手（本地开发版）”快捷方式。测试文件保留于 Videos/ZSir Client Tests；普通使用默认保存于 Videos/ZSir Recordings（可更改）。
- 未验收：1 小时以上录制、会议共存、设备拔出、磁盘耗尽、睡眠/断电、FCP 导入、摄像头。当前为未签名开发版，尚未制作正式发行安装包。
