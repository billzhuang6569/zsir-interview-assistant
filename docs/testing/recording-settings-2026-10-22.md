# 录制设置 V2 验收记录

日期：2026-10-22。状态：用户已确认本机设置体验，授权四平台发布 v0.2.0；真实媒体采集与跨硬件限制仍按下文记录。

## 通过

- macOS SwiftPM 构建及现有脚本 .app 打包，ad hoc 签名。
- CaptureChecks：三档码率、奇数尺寸归一化、非法尺寸；三档无音轨 MP4 封装、可读取及恢复副本，原文件字节不变。
- 原有回归：活动 Take 锁、SIGKILL 后恢复、符号链接输入排除；预览共享像素但不污染录制元数据；机位输出；4K 解码；12 秒 H.264/AAC 编码、14 秒时间线与完整解码。
- 权限与 UI 检查：授权状态映射、重复请求、迟到回调、忙碌锁定、首次引导、录制时间码与边缘收起恢复。新增设置默认值、持久化和无效档位回退断言。
- Windows x64：.NET 8.0.426 Release 构建，零警告零错误；--check-settings 检查档位计算和非法尺寸。独立目录：C:/Users/Administrator/zsir-settings-review-20261022。
- CUA 本机观察：开发版设置窗口已显示，双源卡片、缺权限占位、三档质量及推荐色块、保存位置/高级设置入口可见；打开系统设置按钮抵达录屏与系统录音页。
- git diff --check。

## 未验证与限制

开发构建当前报告摄像头/麦克风和录屏尚未授权，未替用户改变系统隐私设置。系统列表中的旧安装开关状态不证明当前 ad hoc 开发构建已获授权。

真实摄像头预览、电平、屏幕快照、正式录制及热插拔仍需用户授权后验收。浮窗真实拖放是否被各 macOS 版本接受、窗口跟随体验、长录与会议共存未验证。没有对 Intel Mac / Windows ARM 做真机测试，也未做本轮 Windows 完整媒体 smoke test。

## 用户查看

运行工作区 `dist/ZSirCapture.app`，从主界面「录制设置」进入。可以切换画质、打开高级设置，或点「打开系统设置」检查浮动引导。正式 `/Applications/庄Sir采访录制助手.app` 保留原版。

## 权限浮窗修复

- 修复跟随：从系统设置进程的窗口元数据读取边界，转换多屏坐标并持续定位浮窗；不读取窗口截图或标题。
- 修复拖动：关闭 isMovable 和 isMovableByWindowBackground，保留应用文件拖动。
- Swift 构建、UI 自检及 diff 检查通过；增加右侧/左侧摆放、负坐标外接屏、窄屏边界断言。修复版已重开。
- CUA 可确认系统设置入口，但当前接口聚焦主设置 sheet，未完整验证浮窗移动跟随和实际拖动；留待用户现场复测。

- 不遮挡修正：左右侧均无完整空间时隐藏，恢复空间后自动显示。新增跨位置断言验证所有返回矩形均在屏幕内且不与设置窗口相交。
