# v0.3.0 发布验证（2026-10-22）

## 范围

六个独立安装ZIP：macOS13+完整版ARM64/Intel、macOS12.3兼容版ARM64/Intel、Windows x64/ARM64。根目录VERSION为唯一发行版本。Windows本轮保持桌面与系统声音功能，未加入摄像头/麦克风。

## Mac

- 四包Release编译、ad-hoc签名检查、Info.plist版本/产品标识/最低系统、Mach-O架构/最低系统检查。SwiftPM的共享Package最低版本为12.3；构建脚本显式向编译器传入目标，防止完整版被降为12.3。最终完整版二进制与plist均为13.0，兼容版均为12.3。
- 四包运行 `--check-updates`、`--check-permissions`、`--check-recording-ui`。Apple Silicon原生执行，Intel通过Rosetta；不是旧系统/Intel物理机验收。
- 完整版和兼容构建CaptureChecks覆盖三档静音成片、原文件保留、SIGKILL恢复、空输入/异常路径、单/双路合成输出、4K编码解码。历史完整记录保留在同目录。
- 更新选择覆盖稳定版本数值比较、预览/撤回跳过、等版/旧版/缺架构/高系统要求及edition隔离。模拟网络覆盖200、304缓存/无缓存重试、403/429退避、超大响应、非法JSON、离线、超时、不安全URL、忙碌/关闭自动检查。更新设置已独立渲染检查。
- 将生产Updates.swift直接编译为隔离的0.2.0测试应用，用真实HTTPS清单验证来源切换、忙碌延迟、忽略持久化、手动再次发现、稍后同次运行不再提醒/下次启动提醒，以及HTTP失败保留原来源；未点击实际下载按钮。

## Windows

最终ZIP在用户Windows11 Pro x64（build26200）实机console会话、Limited权限、中文/空格目录执行。PATH仅系统目录，DOTNET_ROOT指向不存在目录，未使用预装.NET或编码器；并非干净系统镜像，也没有断网。

- 最终x64 ZIP SHA256：`2bbefaa77d6f84a3d2db53feded84439e02b71348adc705fab66033fda7797f0`。
- 18秒短录通过：2560×1440 H.264、48kHz双声道AAC，成片21.20秒；三处音画偏差约+40/+23/−37ms。完整解码、静音第二次录制、边缘收起/恢复、缺组件/缺设备阻止录制、编码器中断素材可读全部通过。
- 用户明确改为约9分钟即可，随后通过正常“停止并保存”按钮结束，实际成片634秒（10分34秒）。H.264/AAC两轨均634秒，19016视频帧，约29.994fps；完整解码通过，音频不连续计数0，首个标记偏差+40ms。录制期间采样编码器内存约1.58–1.59GiB、界面约64–65MiB，启动4帧丢弃后未增加。
- 原1800秒自动化因用户要求提前停止，结果保留为中止（脚本记录Recording stopped unexpectedly），不能改成30分钟通过。已单独验证成片；第二/第三个定时标记未到达，未验收尾端同步漂移。脱敏结果见windows-v0.3.0-short-2026-10-22.json与windows-v0.3.0-extended-2026-10-22.json。
- ARM64自包含程序编译及PE架构验证；包内x64编码工具在x64机完成编码、探测、解码、音频与视频分析检查。这不是Windows ARM物理设备验收。
- 工具来自固定FFmpeg9.0.2/x264源码、最小静态构建，包内许可证与对应完整源码/构建脚本随Release提供；源码包不含测试机信息。

## 发布门禁

`generate-updates.py`逐一核验六包ZIP完整性、版本、架构、minOS、工具哈希和源码存在后生成清单/校验和。`publish-release.py`创建草稿、上传九项资产、对比GitHub端大小与SHA256后才公开；缺包、版本错误或哈希不一致阻止完整发布。已用最终六包验证通过路径及历史清单保留，并注入缺包、损坏ZIP、篡改ffmpeg.exe，均被拒绝。源码归档内原始源码哈希、构建脚本与通知内容和仓库/两Windows包一致。

## 未验收

无macOS12/13、Intel Mac或Windows ARM64物理设备采集验收；没有部署用户自有服务器。自定义来源使用真实HTTPS静态文件验证协议，不代表生产服务器运维验收。1小时以上采访、多屏/DPI/热插拔、睡眠/断电、干净系统离线及后期软件导入由 [#29](https://github.com/billzhuang6569/zsir-interview-assistant/issues/29) 持续跟踪。macOS无公证/发行签名，Windows无发行签名。
