# Windows 缺编码组件修复与实机验收

> 此文件保留前期开发包的历史验证状态。v0.3.0最终包与发布结果见 [本轮发布验证](v0.3.0-release-2026-10-22.md)。

2026-10-22，关联 #27。修复为本地测试构建，基于0.2.0，不替换已发布资产、不提交代码。

## 修复

打包阶段复用固定FFmpeg9.0.2下载和SHA256校验，将ffmpeg/ffprobe、上游LICENSE/README、来源说明包含在ZIP。最终用户无需CMD、SDK、PATH或联网补装。兼容原开发用安装脚本；工具复制改为xcopy，支持TEMP和输出目录在不同盘，修复原move目录跨盘失败。出包前验证H.264/AAC编码、ffprobe双轨识别和完整解码；版本从csproj读取。组件缺失提示重新完整解压，录制前拒绝且不创建Take，新增两个缺组件回归。

## 已验证

用户提供Windows11 x64 10.0.26200实机，通过Tailscale/SSH连接，测试程序在已登录的console会话1中以Limited权限运行。解压最终ZIP到中文/空格路径，测试进程PATH仅保留Windows系统目录，DOTNET_ROOT指向不存在目录。没有借用机器原有FFmpeg；应用按自身tools绝对路径启动。

- 最终ZIP完整性、附带组件与哈希验证通过；错误工具压缩包被拒绝。
- --check-settings通过；--smoke-test通过，退出0。
- 2560×1440桌面视频和48kHz双声道AAC，21.37秒首条完整解码；三次闪光/测试音偏差60/30/40ms。
- 连续第二次18.33秒录制、静音保留音轨、边缘收起/展开/停止恢复、无效设备拒绝。
- 强制终止本次测试编码器后，应用报告异常、保留分离素材且中断视频可读取。
- 窗口截图人工查看：计时、预览、停止按钮可见，无缺组件弹窗。

原始报告保留在本地dist/windows-fix27-evidence/；脱敏结果见同名JSON。测试机地址和凭据未写入文档。

## 边界

并非重装的干净系统；未断开Tailscale网络，验证的是无PATH/工具下载依赖。此机无摄像头，Windows客户端本来也未实现摄像头/麦克风。未做ARM64实机、30分钟以上录制、多屏热插拔、睡眠和断电测试。当前修复不代表这些验收已完成。

公开发布前须补齐所带静态FFmpeg及外部库的完整对应源码/构建材料；现附上游许可、版本与FFmpeg源码链接，不将单个FFmpeg源码链接冒充完整对应源码。参见clients/windows/RECORDING-TOOLS.md。
