## 术语

| 术语 | 含义 |
|---|---|
| **会话 (Session)** | 一次采访。由导演在控制端创建，生成 6 位会话码；嘉宾客户端凭码加入 |
| **客户端 (Client)** | 装在嘉宾电脑上的录制程序，角落小浮窗 |
| **控制端 (Control)** | 导演打开的网页，可多人同时打开 |
| **Relay** | 你的服务器上的中转服务，所有指令与状态经它转发 |
| **轨道 A / cam** | 摄像头画面 + 话筒声音 |
| **轨道 B / screen** | 桌面画面 + 系统声音 |
| **静帧 (Frame)** | 某一时刻某轨道的一张 JPEG 截图，用于远程检查 |
| **宫格图 (Contact sheet)** | 录制完成后每 30 秒抽一帧拼成的网格大图 |
| **结束任务 (Finish)** | 嘉宾端自我卸载并清理，保留录制文件 |
