# 采访助手交互原型

第2套 Control Room 修订稿的可交互实现，所有媒体、设备、录制、保存和卸载均为模拟。不会调用摄像头/麦克风/屏幕权限，也不会访问输出目录或卸载软件。

## 运行

在本目录执行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

导演页面为 `/`，嘉宾小窗演示为 `/?view=guest`。打开两个导演标签页和一个嘉宾标签页即可演示状态同步。使用相同主机名和浏览器配置；localhost与127.0.0.1是不同存储域。

## 试用流程

1. 嘉宾页右上角展开设置，选择模拟设备、编辑输出目录，试录10秒，完成后收起。
2. 导演页选择机位、检查画面、开始3秒倒计时，可取消再开始；嘉宾页同步状态。
3. 停止后等待模拟保存，打开素材检查。短视频显示首尾；“载入录制示例”模拟12分36秒长素材，停止后可试宫格分页、机位切换和单帧放大。
4. 顶部演示工具可模拟断网与保存失败。断网时导演按钮禁用，嘉宾仍可停止；保存失败后可重试。
5. 两端“结束任务”均弹出说明，确认后保存、撤权、模拟卸载，再关闭嘉宾小窗。已录模拟Take保留，所有控制禁用。用“重置演示”开启新任务。

## 边界

- 使用localStorage事件与Web Locks串行处理同浏览器多标签状态，不是远程服务器通信。跨电脑、不同浏览器不共享状态。
- 固定本地地址无账号；没有实现生产环境共享链接凭据、安全协议或真实授权。
- 嘉宾小窗是网页内固定定位的260×100左右区域，为保证操作可读略大于240×88初始目标；不是操作系统置顶窗口，不会出现在网页以外。
- 图像是生成的静态示例，宫格重复使用它们；自动更新仅模拟时间戳，声音条不是设备输入。
- 模拟数据存在浏览器本地，可重置；关闭所有页面后没有后台录制，重开按时间恢复模拟状态。
- 共享“载入录制示例”会重置其他页面的模拟任务。所有演示按钮都只影响本机模拟数据。

## 检查

```sh
npm test
npm run build
```
