# design/

UI 设计稿。可编辑版本在 Claude Design 画布：https://claude.ai/artifact/MHBJFzhu9K2yh2SYgjSc1N

`canvas/` 是画布的源文件备份（`.dc.html` 为画布专用组件格式，依赖画布运行时，不能直接在浏览器打开；以画布为准）。

## 画板

| 文件 | 内容 | 尺寸 |
|---|---|---|
| `Main.dc.html` | 控制端 · 房间页（导演）：顶栏、房间列表、邀请码、嘉宾卡片（两路静帧 / 指标 / 操作行）、事件日志、停止确认弹层 | 1440 宽，响应式 |
| `Float.dc.html` | 客户端 · 角落浮窗 4 种状态：就绪 / 倒计时 / 录制中 / 警告 | 浮窗 280×96 |
| `Onboarding.dc.html` | 客户端 · 首次启动第 4 步「自检」（下一步为「输入邀请码」，再之后是欢迎卡，见 01 §4.2） | 800×560 窗口 |
| `Sheet.dc.html` | 控制端 · 宫格图检查弹层（A/B 切换） | 1000×700 |

## 视觉约定

- 深色监视器风格（导演常在暗环境看监视器），背景 `#141518`，面板 `#1d1f24`，边框 `#2c2f36`。
- 语义色：录制红 `#e5484d`、正常绿 `#3ecf8e`、警告琥珀 `#f0b429`、系统声蓝 `#5b9cf5`、操作蓝 `#8fb8ff`。
- 字体：Noto Sans SC（界面）、JetBrains Mono（时间码、码率、邀请码）。
- 所有需要辨别的状态同时用颜色与文字/形状表达，不只靠颜色。
- 嘉宾端一切文案用动作句，不出现技术术语。
