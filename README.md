# 庄Sir线上采访助手

让嘉宾录下本地高清采访素材，让导演远程确认画面、声音和录制状态。

**项目处于产品设计与技术验证准备阶段。当前没有可安装客户端，也没有已实现的录制服务。**

每次采访分别输出「摄像头＋话筒」和「桌面＋系统声音」两条本地视频。支持方向为 macOS 与 Windows；多人通过固定网址免登录进入导演网页，共享状态并控制录制、检查录后素材。嘉宾端常驻右上角极小状态窗，两端均有“结束任务”以保存素材、撤销控制并卸载关闭嘉宾端。中转使用用户提供的服务器。原始视频不经云端转发。

## 第一版原则

1. 本地录制优先，网络故障不能终止已经开始的录制。
2. 摄像头文件只主动混入所选话筒；桌面文件只主动混入系统播放声音。
3. 保留完整系统声音，包括会议声音，不做应用筛选或会议声音剔除。
4. 客户端写盘确认后才显示「正在录制」，文件验证后才显示「已保存」。
5. 宫格图从落盘视频解码，不能以预览截图代替素材验证。
6. 嘉宾明确授权本次远程检查和控制，始终保留本地停止权。
